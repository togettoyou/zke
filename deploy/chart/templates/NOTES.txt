ZKE has been installed as release {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

1. Wait for the Server to become ready:

     kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "zke.server.fullname" . }}

2. Open the Console. With the default ClusterIP Service, forward the ports:

     kubectl -n {{ .Release.Namespace }} port-forward service/{{ include "zke.server.fullname" . }} 8080:{{ .Values.server.service.httpPort }} 8081:{{ .Values.server.service.podAccessPort }}

   Browse to http://127.0.0.1:8080 and follow the first-run page to choose the
   global administrator username and password.

3. Create a Tenant and a Project, then enroll a Cluster.
