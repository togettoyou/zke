# Web Desktop

ZKE Web Desktop 是具有桌面操作体验的 Kubernetes 管理工作空间。

规划中的桌面能力包括：

- 桌面应用图标与应用启动；
- 独立应用窗口；
- 窗口最小化、最大化和关闭；
- 多窗口切换与窗口层级管理；
- 任务栏或 Dock；
- 当前运行应用状态；
- 用户与系统状态区域；
- 多任务操作。

不同应用具有不同的资源作用域。有些应用提供多集群全局视图，有些应用要求先选择一个目标集群。Web Desktop 将持续显示必要的租户、项目、集群或 Namespace 上下文，帮助用户理解当前查看和操作的范围。

Web Desktop 是 ZKE 的交互载体，不是浏览器中的完整操作系统。
