# 产品愿景与设计原则

ZKE（Z Kubernetes Engine）是一款构建在 Kubernetes 之上的云原生管理平台，面向多集群管理、容器服务、作业调度、AI 算力、模型服务、统一可观测性与 AI 辅助排障场景。

ZKE 不是 Linux 发行版，也不是 Kubernetes 的替代品。它是构建在 Kubernetes 之上的 Kubernetes 管理与算力平台。

## 设计原则

1. **以 Kubernetes 为统一基础设施底座**：工作负载最终运行在具体 Kubernetes 集群中。
2. **Server + Agent 管理多集群**：Agent 主动连接 Server，适应私有网络、混合云、多云和边缘环境。
3. **领域能力分层**：将容器、作业、算力、模型与可观测性能力组织在同一平台内。
4. **AI 辅助而非无审核自治**：AI 提供分析证据、根因判断和修复建议，执行前仍需权限检查与用户确认。
5. **全局查看、定域执行**：跨集群汇总信息，实际操作必须落到明确的集群与资源。
6. **默认受控与可审计**：敏感操作需要验证权限、确认目标、评估影响并记录审计日志。

> **作用域原则：全局观察，按集群执行；全局管理算力，按策略选择落点。**

## 适用场景

- 企业多 Kubernetes 集群统一管理
- 私有云和混合云 Kubernetes 管理
- GPU 集群和 AI 算力管理
- AI 训练与批处理作业
- 大语言模型推理服务
- Kubernetes 可观测性
- AI 辅助故障定位
- 受控的智能运维
