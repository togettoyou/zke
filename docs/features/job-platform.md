# 作业平台

作业平台当前按单集群应用设计。用户进入时需要先选择 Kubernetes 集群，作业、队列、配额和调度策略均属于当前集群。

规划能力包括：

- 作业创建与作业模板；
- 批处理任务、AI 训练任务、分布式训练任务和 GPU 作业；
- 作业队列、优先级与资源配额；
- 作业暂停与恢复；
- 作业日志、状态跟踪和运行历史；
- 作业失败分析；
- 调度状态与资源使用情况。

> [!NOTE]
> 作业调度技术仍在选型中，当前评估 **Volcano** 与 **Kueue**，尚未确定最终方案。

未来可能规划多集群“全局作业中心”，汇总所有集群的作业、队列压力和资源使用情况。作业的实际创建和执行仍将发生在具体 Kubernetes 集群中。
