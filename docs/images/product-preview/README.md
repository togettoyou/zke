# 产品预览图

README 与文档引用的截图统一放在这里。文件名即引用路径，替换图片时保持文件名和扩展名不变，不需要改动 Markdown。

## 拍摄约定

- 分辨率与现有截图一致：`2956 × 1644`（Retina 下 1478 × 822 的两倍图）；动图 `1468 × 816`。
- 使用浅色主题，浏览器不带书签栏与扩展图标。
- 只使用演示数据：不得出现真实集群地址、真实用户名、Token、证书或客户名称。
- 截图前把窗口摆到该应用的默认尺寸，保留桌面背景与 Dock，让"桌面"这一产品形态本身可见。
